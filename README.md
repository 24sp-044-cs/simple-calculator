# 🧮 Simple Calculator

A clean and user-friendly calculator web application built with **Python** and **Streamlit**. It performs basic and advanced arithmetic operations with proper input validation and error handling.

## 🌐 Live Demo

👉 [Open the Live App](https://simple-calculator-xfon7nn6tcwj7b2qwkunsq.streamlit.app/)

## ✨ Features

- Addition, Subtraction, Multiplication and Division
- Power (exponent) and Modulus operations
- Handles division by zero with a clear error message
- Supports decimal (floating-point) numbers
- Simple, responsive interface

## 🚀 Installation and Usage

1. **Clone the repository**
```bash
   git clone https://github.com/24sp-044-cs/simple-calculator.git
   cd simple-calculator
```

2. **Install dependencies**
```bash
   pip install -r requirements.txt
```

3. **Run the application**
```bash
   python -m streamlit run app.py
```

4. Open `http://localhost:8501` in your browser.

## 📖 How It Works

1. Enter the first and second number.
2. Select the required operation from the dropdown.
3. Click **Calculate** to see the result.
